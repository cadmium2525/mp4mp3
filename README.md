# おとだけ

iPhone の画面収録やカメラで撮った動画から、**音声だけを取り出す** Web アプリです。
スマートフォンでの利用を前提に作っています。

- サーバー不要・完全無料（GitHub Pages で公開）
- ファイルは端末の外に一切送信されません（すべてブラウザ内で処理）
- ホーム画面に追加すればアプリのように使え、オフラインでも動作します

## できること

| 機能 | 内容 |
| --- | --- |
| 音声の取り出し | MOV / MP4 などの動画 → MP3（64〜320kbps）、WAV、または M4A（再エンコードなし・劣化ゼロ） |
| 音量の統一 | ラウドネス（LUFS, ITU-R BS.1770）またはピークで複数ファイルの音量をそろえる。音割れ防止のリミッター付き |
| リネーム | 「1曲目・2曲目…」の一覧でまとめて名前をつけて一括適用、並べ替え |
| トリミング | 波形を見ながら開始・終了位置を指定、試聴 |
| 無音カット | 前後の無音を自動で削除 |
| フェード | フェードイン・フェードアウト |
| 結合 | 複数ファイルを1つにつなげる（並べ替え可） |
| その他 | モノラル化、サンプリング周波数変更、MP3 タグ（タイトル・アーティスト・アルバム）、共有シートで「ファイル」に保存、ZIP 一括ダウンロード |

音声ファイル（MP3 / M4A / WAV など）を入れて、音量統一やリネームだけに使うこともできます。

## つなぐ（動画エディタ）

`editor/` にある、iPhone で使える動画編集アプリです（公開 URL の末尾に `/editor/`）。

- 比率：ショート/リール/TikTok（9:16）、YouTube（16:9）、正方形、インスタ縦長（4:5）
- カット編集：分割、両端のつまみでトリミング、並べ替え、複製、速度変更（0.25〜4倍）
- 切り替え効果：クロスフェード、黒/白フェード、スライド、ワイプ、ズーム
- テキスト：テロップ・字幕・タイトルなど 7 スタイル、プレビュー上でドラッグ配置、アニメーション
- 音：BGM・効果音の追加、音量、フェード、ループ、クリップごとの音量
- 映像：画面いっぱい/全体表示、拡大・位置調整、ケン・バーンズ、明るさ・コントラスト・彩度
- 図形：四角・丸・星・ハート・矢印・吹き出しなど 12 種類、出かた・続く動き・移動/拡大/回転のアニメーション
- エフェクト：ぼかし、手ぶれ、ズーム鼓動、グリッチ、RGBずれ、モノクロ、周辺減光、フィルム粒子、シネマ帯、フラッシュ、紙吹雪、雪、キラキラ、ハート
- ワイプ（PiP）：動画・写真を重ねる。丸・角丸の切り取り、ふち、影、音量
- 切り抜き：AI による人物の切り抜き、タップした物の切り抜き、グリーンバック（すべて端末内）
- キーフレーム：位置・大きさ・回転・不透明度・3D 角度を時間に沿って自由に動かす
- 3D：テキスト・図形・ワイプの遠近つき 3D 回転、3D フリップ・キューブのトランジション、立体文字
- 文字の装飾：グラデーション（ゴールド・レインボーなど）、二重ふち、光彩（ネオン）
- 書き出し：MP4（iPhone では H.264 + AAC）、720p〜4K、共有シートから写真アプリへ保存
- プロジェクトと素材は端末内（IndexedDB）に自動保存、元に戻す/やり直し
- 編集内容は JSON でやり取りでき、Claude などの AI に編集を頼める（形式は [editor/PROJECT_FORMAT.md](editor/PROJECT_FORMAT.md)）。無音区間の自動検出と、素材の「コマ一覧」画像の書き出しで、AI に映像の中身も伝えられる
- `node editor/tools/render.mjs project.json 素材フォルダ out.mp4` で PC からも同じエンジンで書き出し可能

動画の読み書きには [Mediabunny](https://mediabunny.dev/)（MPL-2.0, `editor/lib/LICENSE.mediabunny`）、切り抜きには [MediaPipe](https://github.com/google-ai-edge/mediapipe)（Apache-2.0, `editor/lib/mediapipe/LICENSE.txt`）を使っています。
書き出しは WebCodecs を使うため iOS 16.4 以降の Safari が必要です（音声付きの書き出しは iOS 26 以降）。

## 公開方法（GitHub Pages・0円）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `/(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/mp4mp3/` で使えるようになります

iPhone では Safari で開き、共有ボタン →「ホーム画面に追加」するのがおすすめです。

## 構成

ビルド不要の静的サイトです。

- `index.html` / `css/style.css` — 画面
- `js/app.js` — 画面の操作、デコード（Web Audio API）、共有・ダウンロード
- `js/worker.js` — 解析・音量統一・リミッター・エンコード（Web Worker）
- `js/mp4.js` — MOV/MP4 から AAC 音声トラックを取り出し、M4A / ADTS に組み直す（Safari が .mov を直接デコードできないため）
- `js/zip.js` — ZIP 作成
- `lib/lame.min.js` — MP3 エンコーダー [lamejs](https://github.com/zhuker/lamejs)（LGPL, `lib/LICENSE.lamejs`）
- `sw.js` / `manifest.webmanifest` — オフライン対応・ホーム画面アイコン

ローカルで試す場合：`python3 -m http.server` を実行して `http://localhost:8000` を開く。

## 注意

- 音声は端末のメモリに展開して処理するため、極端に長い動画（目安：iPhone で1本60分超）は途中で止まることがあります。
- 動画内の音声が AAC 以外（リニアPCMなど）の場合は、ブラウザが直接読める形式でない限り変換できません。
