    使い方

    基本：ひな形を選ぶ → トラックの帯（クリップ）をタップして選び、もう一度タップで中身を編集 → ▶ で再生 → 右上の「書き出す」で WAV / MP3 に。

    ピアノロール：空いたところをタップで音を置く。音をタップで選択、ドラッグで移動、右端をドラッグで長さ。「和音」を選ぶとタップで和音ごと置けます。

    見える化：「見える化」タブで、再生中の音の周波数・音量をリアルタイムに表示。「全体を解析」で、ラウドネス・帯域バランス・和音・スマホのスピーカーでの聞こえ方まで調べて、気をつける点を教えてくれます。

    自動ミックス：ミキサーの「自動ミックス」で、各トラックの音量を役割（ドラム・ベース・メロディなど）に合わせて自動で整えます。

    つなぐで使う：書き出した音を「ファイル」に保存し、つなぐの「音楽」から読み込めます。

    Claude と一緒に作る：「…」→「JSONをコピー」と「見える化シート」の画像を Claude に送ると、音の状態が伝わります。返ってきた JSON を「JSONを貼り付け」で反映できます。形式は FORMAT.md。

    保存：曲はこの端末のブラウザ内に自動保存されます。Safari の Webサイトデータを消すと消えるので、大切な曲は JSON でも保存してください。
