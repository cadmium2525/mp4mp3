プロジェクト

    使い方

    基本：動画や写真を追加 → タイムラインを左右にスクロールして位置を合わせる → 下のボタンで分割・テキスト・音楽などを追加 → 右上の「書き出す」。

    選ぶ・調整：タイムラインのクリップをタップすると選択。もう一度タップで詳細設定。選択中は両端のつまみをドラッグして長さを調整できます。

    テキストの位置：プレビュー上でテキストを指でドラッグ。

    保存先：書き出した動画は「共有」→「ビデオを保存」で写真アプリへ。そこから YouTube・TikTok・Instagram に投稿できます。

    プロジェクトの保存：編集内容と素材はこの端末のブラウザ内に自動保存されます。Safari の履歴・Webサイトデータを消すと消えるので注意。

    Claude と一緒に作る：編集画面の「…」→「JSONをコピー」で編集内容を文字にできます。Claude に「このテロップを直して」などと頼み、返ってきた JSON を「JSONを貼り付け」で反映できます。
