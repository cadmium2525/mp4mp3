      形式

      動画の中の音声をそのまま取り出すので、音質が一切変わらず一番速いです。使える加工はトリミングだけです（音量の統一・無音カット・フェード・結合は使えません）。

      音量をそろえる

      人の耳の感じ方に近い「ラウドネス（LUFS）」をそろえます。複数ファイルの音量差をなくしたいときはこれ。

      一番大きい音が指定の大きさになるように調整します。

      ← 小さく大きく →

      ゲームのBGMや効果音が大きすぎるときは、-24 くらいから少しずつ下げて、実際に鳴らしながらちょうどいい大きさを探してください。全ファイルが同じ聞こえ方の大きさにそろいます。

        使い方・よくある質問

        基本の使い方

        1. 「動画・音声を選ぶ」をタップし、写真ライブラリまたはファイルを選択から動画を選びます。
        2. 必要ならファイル名を変えたり、波形の下のスライダーで使う範囲を切り取ります。
        3. 下の「変換する」をタップ。
        4. できあがったら「共有」→「"ファイル"に保存」で iPhone に保存できます。LINE などに直接送ることもできます。

        ホーム画面に追加するとアプリのように使えます

        Safari の共有ボタン →「ホーム画面に追加」。一度開けばオフラインでも使えます。

        ファイルはどこかに送信されますか？

        いいえ。読み込みも変換もすべてこの端末の中（ブラウザ内）で行われ、ファイルが外部に送信されることはありません。

        長い動画で止まってしまう

        音声はいったん端末のメモリに展開して処理します。iPhone では目安として1ファイル60分程度まで。止まる場合は「モノラル」にするか、ファイルを分けて試してください。変換中は画面を閉じたり、別のアプリに切り替えないでください。

        「聞こえ方で統一」とは？

        放送や音楽配信でも使われている ITU-R BS.1770（LUFS）という基準で、人が感じる音の大きさをそろえます。音を大きくして音割れしそうなところは自動で抑えます（リミッター）。

        MP3 エンコードに lamejs（LAME の JavaScript 移植, LGPL）を使用しています。
